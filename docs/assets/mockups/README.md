# Snake & Math — visual concept v1

Two portrait raster mockups generated with the built-in image generation tool after reading docs/snake-math-prd.md and inspecting both supplied reference assets. These are visual concepts, not editable Figma frames or implemented Android screens. Reference art was inspected for inspiration; no reference files were composited into the outputs. Originality is a design intent, not a legal clearance guarantee.

- home-v1.png: both mode selections, individual illustrative best scores, settings, original mascot concept.
- mdas-gameplay-v1.png: five lives, persistent precedence question, three answer apples, pause, swipe-only instruction. 5 + 3 × 2 = 11; distractors 16 and 13. Board grid and object alignment are illustrative and must be made deterministic in implementation.

Portrait orientation and illustrative score values are draft design choices. No game code changed.
