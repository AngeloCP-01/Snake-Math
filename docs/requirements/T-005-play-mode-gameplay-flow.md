## Requirement

Players can use Home → PLAY → actual Classic/MDAS mode selection → an honest non-playable destination showing their selected mode and MDAS level. Preserve T-004 Home/title/Settings behavior, reject invalid configuration, and distinguish same-process Activity recreation from a new process; this completes M1.7's agreed navigation foundation without implementing playable gameplay.
