# Deprecated design archive

[deprecated-design-assets-2026-11-20.zip](deprecated-design-assets-2026-11-20.zip) preserves superseded files removed during the 2026-11-20 cleanup. **History and provenance only; do not use these assets or prototypes for implementation.** The current allowlist is [docs/assets/README.md](../assets/README.md).

The archive contains:

- Earlier home/gameplay mockups and combined presentations.
- The old head PNG, fourteen-piece sprite sheet and failed assembly/comparison studies.
- Segmented and smooth-body v2 prototypes, plus their earlier render previews.
- Earlier HTML UI studies and phone/tablet screenshots from `docs/design/`.
- Original inspiration artwork/downloads and historical generation notes.

Forty obsolete files were removed from their active paths after verifying their archived copies. The previous mockup README was also saved before replacing its index. `MANIFEST.json` inside the ZIP records all 41 original paths, byte sizes and SHA-256 hashes; `DEPRECATED-DO-NOT-USE.md` explains the status.

Historical HTML snapshots and links inside the ZIP are frozen and may reference files from the former project layout. Keep any manual extraction separate from the active asset folders. The archive is not an Android resource bundle.
